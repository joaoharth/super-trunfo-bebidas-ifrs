# Super Trunfo de Bebidas

Esse é um jogo feito em Python para a disciplina de programação do IFRS. O jogo é baseado no Super Trunfo, mas utiliza cartas de bebidas.

O jogador recebe uma carta e escolhe um atributo para comparar com a carta do computador. Quem tiver o melhor valor vence a rodada. Também existem cartas especiais chamadas Super Trunfo.

O jogo possui sorteio de cartas, comparação de atributos, imagens das bebidas e resultado de cada rodada.

Foi utilizado Python, Tkinter, Pillow e JSON para desenvolver o jogo.

No repositório também estão incluídos os arquivos necessários para o funcionamento do jogo, como o arquivo com os dados das cartas e as imagens das bebidas, além dos detalhes e instruções para executar o programa.

O objetivo do trabalho é praticar os conteúdos de programação aprendidos em aula.
